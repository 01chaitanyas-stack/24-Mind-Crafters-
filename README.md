# CityPilot AI

CityPilot AI is a smart travel planning web application that helps users generate personalized itineraries, discover places, and manage travel budgets. Built with React, Vite, and Tailwind CSS, it leverages AI-driven insights and interactive maps for a seamless travel experience.

## Features

- **AI-Powered Itinerary Generation**: Get custom travel plans based on your preferences and budget.
- **Interactive Map**: Visualize places, hotels, food spots, and transport options using Leaflet and React-Leaflet.
- **Authentication**: Secure login and signup for personalized experiences.
- **Budget & Cost Breakdown**: See detailed cost estimates for your trip.
- **Modern UI**: Responsive design with Tailwind CSS and engaging animations.

## Project Structure

- `src/pages/` — Main pages: Home, Itinerary, Login, Signup
- `src/_components/` — UI components: Navbar, Map, Cards, etc.
- `src/engine/` — Core logic: itinerary planner, budget filter, scoring, insights
- `public/data/` — Sample data for places, food, hotels, transport, bus stops

## Getting Started

### Prerequisites
- Node.js (v18 or newer recommended)
- npm or yarn

### Installation
1. Clone the repository:
   ```sh
   git clone <repo-url>
   cd citypilot-ai 00
   ```
2. Install dependencies:
   ```sh
   npm install
   # or
   yarn install
   ```

### Running the App
Start the development server:
```sh
npm run dev
# or
yarn dev
```
The app will be available at `http://localhost:5173` (default Vite port).

### Build for Production
```sh
npm run build
# or
yarn build
```

### Linting
```sh
npm run lint
# or
yarn lint
```

## Usage

1. **Sign up or log in** to access personalized features.
2. **Set your travel preferences and budget** on the Home page.
3. **Generate an itinerary** and explore recommended places, food, and transport options.
4. **View your trip on the interactive map** and review the cost breakdown.
